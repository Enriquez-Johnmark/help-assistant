# IDs we accept

> Made up for a demo. Halimbawa Money is not a real company, and every fee, limit and time on this page is invented.

## Accepted IDs
National ID, passport, driver's licence, UMID, SSS ID, PRC ID, postal ID and voter's ID. The ID must not be expired.

## IDs we don't accept
School IDs, company IDs and barangay certificates can't be used to verify a wallet or to claim money.
